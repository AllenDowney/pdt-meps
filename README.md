# pdt-meps

Metadata for the [Medical Expenditure Panel Survey, Household Component (MEPS-HC)](https://meps.ahrq.gov/mepsweb/), built to the [PublicDataToolkit](https://github.com/AllenDowney/PublicDataToolkit) standard.

**Status:** three data years (2022, 2023, 2024), each with two tables linked on DUPERSID: 37 variables from the full-year consolidated file (design, demographics, health status, the K6 and PHQ-2 mental-health items, use and expenditure) and the office-based visits file whole; 164 links by AHRQ's naming convention. The terms aren't decided yet, so nothing here may ship.

## What the dataset is

AHRQ's survey of health care use, expenditures, sources of payment and insurance coverage of the US civilian noninstitutionalized population, from overlapping two-year panels, released as annual person-level and event-level files.

## Terms of use

The terms are at https://meps.ahrq.gov/mepsweb/data_stats/download_data_files.jsp. They haven't been reviewed yet, so nothing built from this repo may ship (STANDARD.md §8). Once a person has decided them, summarize them here; the decision is in [`dataset.yaml`](dataset.yaml).

## How to get the data

The files are listed in [`sources.yaml`](sources.yaml), with where to get each and its checksum: AHRQ posts each file's data (Stata and other formats), codebook and documentation at meps.ahrq.gov without registration. `make download ARGS=--accept-terms` fetches them; unzip each `.dta` and run `pdftotext -layout` on each PDF into `data/interim/` before `make build`.

## How to use the metadata

- `metadata/releases/<release>/variables.jsonl`: one record per variable, with where each fact came from.
- `docs/`: a page per variable, generated by `make views`.
- `agent/`: shards for LLMs; start with `agent/SKILL.md`.

## How to cite

Agency for Healthcare Research and Quality. Medical Expenditure Panel Survey, Household Component. Rockville, MD.

## How to rebuild

With the sources in `data/raw/` and a PublicDataToolkit checkout next to this repo:

```bash
make build
make views
make check
```
