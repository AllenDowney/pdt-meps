# pdt-meps

Metadata for the [Medical Expenditure Panel Survey, Household Component (MEPS-HC)](https://meps.ahrq.gov/mepsweb/), built to the [PublicDataToolkit](https://github.com/AllenDowney/PublicDataToolkit) standard.

**Status:** three data years (2022, 2023, 2024), each with two tables linked on DUPERSID: 37 variables from the full-year consolidated file (design, demographics, health status, the K6 and PHQ-2 mental-health items, use and expenditure) and the office-based visits file whole; 164 links by AHRQ's naming convention. The terms are decided (everything ships), but nothing is published yet.

## What the dataset is

AHRQ's survey of health care use, expenditures, sources of payment and insurance coverage of the US civilian noninstitutionalized population, from overlapping two-year panels, released as annual person-level and event-level files.

## Terms of use

The terms are at https://meps.ahrq.gov/mepsweb/data_stats/download_data_files.jsp. Allen Downey reviewed the terms on 2026-11-20: the metadata, the documentation and the common-format data ship, with this notice:

> Source: Agency for Healthcare Research and Quality, Medical Expenditure Panel Survey, Household Component, public use files. Use is subject to AHRQ's Data Use Agreement: the data may be used only for statistical reporting and analysis, and users must not attempt to identify any person or link the data to identifiable records.

## How to get the data

The files are listed in [`sources.yaml`](sources.yaml), with where to get each and its checksum: AHRQ posts each file's data (Stata and other formats), codebook and documentation at meps.ahrq.gov without registration. `make download ARGS=--accept-terms` fetches them; unzip each `.dta` and run `pdftotext -layout` on each PDF into `data/interim/` before `make build`.

## How to use the metadata

- `metadata/releases/<release>/variables.jsonl`: one record per variable, with where each fact came from.
- `docs/`: a page per variable, generated by `make views`.
- `agent/`: shards for LLMs; start with `agent/SKILL.md`.

## How to cite

Agency for Healthcare Research and Quality. Medical Expenditure Panel Survey, Household Component. Rockville, MD.

## How to rebuild

With the sources in `data/raw/` and a PublicDataToolkit checkout next to this repo:

```bash
make build
make views
make check
```

The metadata tools (`make views`, `make check`) need only the toolkit's base install
(`pip install -e ../PublicDataToolkit`). Building or reading the data files (`make data`,
`scripts/extract.py` where the repo has one, and the data checks in `make check`) also
needs pandas, numpy and pyarrow: `pip install -e "../PublicDataToolkit[data]"`. Without
them, `make check` skips the data checks and says why.
